
# Smart Vaccination Management System

## Project Details
- **Project Title:** Smart Vaccination Management System
- **Domain:** Good Health & Well-being
- **SDG:** SDG 3 – Good Health and Well-being
- **Technology:** Java Swing
- **Type:** Desktop GUI application
- **Storage:** Local serialized data file (`vaccination_data.dat`)

## Main Features
1. Admin login
2. Dashboard with statistics
3. Patient registration
4. Patient search
5. Delete patient
6. Vaccination record management
7. Appointment scheduling
8. Vaccination status overview
9. Local data persistence

## How to Run

### Option 1: Command Prompt
Open the folder in Command Prompt:

```text
javac VaccinationManagementSystem.java
java VaccinationManagementSystem
```

### Option 2: VS Code
1. Install JDK 17 or newer.
2. Install the Extension Pack for Java in VS Code.
3. Open this project folder.
4. Open `VaccinationManagementSystem.java`.
5. Click **Run**.

### Login
- Username: `admin`
- Password: `admin`

## SDG Connection
The project supports **UN Sustainable Development Goal 3: Good Health and Well-being** by helping maintain vaccination records, appointments and patient information in an organized digital system.

## Suggested Viva Explanation
"The Smart Vaccination Management System is a Java Swing based desktop application designed to manage patient vaccination information. It provides modules for patient registration, vaccination records, appointment scheduling and a dashboard. I used object-oriented programming concepts such as classes, objects, encapsulation and collections. The GUI is built using Java Swing and data is stored locally using Java serialization. The project is aligned with SDG 3, Good Health and Well-being."
